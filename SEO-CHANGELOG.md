## 1. Architecture & Discovery Findings (Phase 0)

1. **Router Architecture:** Next.js 15 App Router (`src/app/`).
2. **Export Mode:** Static HTML Export (`output: 'export'`) configured in `next.config.ts`.
3. **Trailing Slash Strategy:** `trailingSlash: true` configured in `next.config.ts`. All exported URLs end with a trailing slash (e.g., `https://wardenandsons.in/shop/`) to ensure direct Apache/Hostinger directory matching.
4. **API Routes:** No `/api/` endpoints exist in the repository; pure client-side WhatsApp request builder.
5. **HTML Delivery:** Server-side prerendered static HTML (`SSG`). Main page content, heading hierarchies, copy, and product collections are directly present in the initial HTML response, not client-only JavaScript shells.
6. **Domain Separation:** `wardenandsons.com` is verified to belong to an unrelated painting company in Madison, Wisconsin. It is strictly excluded from all code, sitemaps, robots, canonicals, and metadata.

   - Hero banner uses priority preload with explicit dimensions and WebP encoding.
   - All secondary images are lazy-loaded with reserved aspect-ratio boxes preventing layout shift (`CLS = 0`).
3. **Mobile Tap Target Compliance:**
   - All interactive controls, pill buttons, and quantity counters are calibrated to at least 44x44px.
