## Phase 0 — Discovery Findings

1. **Router Architecture:** Next.js 15 App Router (`src/app/`).
2. **Export Mode:** Static HTML Export (`output: 'export'`) configured in `next.config.ts`.
3. **Trailing Slash Strategy:** `trailingSlash: true` configured in `next.config.ts`. All exported URLs end with a trailing slash (e.g., `https://wardenandsons.in/shop/`) to ensure direct Apache/Hostinger directory matching.
4. **API Routes:** No `/api/` endpoints exist in the repository.
5. **HTML Delivery:** Server-side prerendered static HTML (`SSG`). Main page content, heading hierarchies, copy, and product collections are directly present in the initial HTML response, not client-only JavaScript shells.
6. **Domain Separation:** `wardenandsons.com` is verified to belong to an unrelated painting company in Madison, Wisconsin. It is strictly excluded from all code, sitemaps, robots, canonicals, and metadata.

## External Audit Item Classification (Real vs. False Positive)

| External Audit Item | Classification | Root Cause & Resolution |
| :--- | :--- | :--- |
| **Missing Title & Meta Description** | **FALSE POSITIVE** | Every route has a unique `<title>` and `<meta name="description">` generated by Next.js metadata API. The external auditor likely evaluated pre-rendered client JS or hit a network timeout. |
| **Robots.txt & Sitemap Missing** | **FALSE POSITIVE** / Stale | Both exist at `/robots.txt` and `/sitemap.xml`. Legacy references pointing to `.com` in older builds have been replaced with `https://wardenandsons.in/sitemap.xml`. |
| **Canonical Issues (.com vs .in)** | **REAL** (Fixed) | Prior revisions defaulted to `.com` on select inner pages. Unified under `SITE_URL = "https://wardenandsons.in"` and `getCanonicalUrl()`. |
| **Noindex Found** | **FALSE POSITIVE** | Verified 0 instances of `<meta name="robots" content="noindex">` and no `X-Robots-Tag: noindex` in `.htaccess` or server headers. |
| **Favicon Missing** | **FALSE POSITIVE** | Valid `/favicon.ico`, `favicon-32x32.png`, `favicon-16x16.png`, and `apple-touch-icon.png` exist in `/public` and are linked in `<head>`. |
| **Hreflang Errors** | **FALSE POSITIVE** | The site is single-language (`en-IN`). No multi-language alternates exist; single valid `<html lang="en-IN">` is declared. |
| **0 Words of Content** | **FALSE POSITIVE** | All static HTML files contain full editorial and descriptive copy for newborn, boys, girls, men, women, and uniform categories. |
| **Missing H1 / Heading Levels** | **REAL** (Fixed) | Ensured exactly one H1 per page without skipped heading levels across all routes. |
| **Invalid Structured Data** | **REAL** (Fixed) | Replaced untyped schemas with `schema-dts`. Homepage uses clean `ClothingStore` and `WebSite`; inner pages use `BreadcrumbList`. Removed disputed `FAQPage` and review/rating schemas. |
| **Performance, INP & Mobile** | **REAL** (Fixed) | Optimized LCP image discovery with high priority preloads, resized WebP assets, deferred cart localStorage writes, and ensured 44px minimum tap targets. |
